# Politique de confidentialité — projet (brouillon, à valider)

**Responsable de traitement (côté commerçant)** : [entité à créer au Bénin]. **Côté institution** : Kwedo traiterait
pour le compte de l'institution (sous-traitant) — qualification à confirmer.

## Données traitées
- Identité : nom, téléphone, numéro de pièce (vérification ; le numéro n'est pas conservé dans le prototype).
- Flux du compte marchand : date, montant, sens, contrepartie **anonymisée**, nature. Jamais le contenu des messages,
  les contacts ni le compte personnel.
- Dossiers, décisions, échéances, paiements, relances.
- **Jamais** : genre, origine, religion, santé, opinions.

## Finalités
Estimer la capacité de remboursement, transmettre le dossier aux institutions choisies, suivre le crédit.

## Base légale
Consentement explicite, par institution, révocable à tout moment depuis l'application.

## Destinataires
Seules les institutions pour lesquelles le commerçant a donné son accord. Chaque consultation est journalisée
(qui, quel dossier, quand).

## Durées de conservation
À définir avec l'APDP (phase 2). Le retrait du consentement coupe l'accès aux nouvelles données ; l'historique d'un
crédit en cours reste chez le prêteur selon ses obligations légales.

## Droits
Information, accès, rectification, suppression, opposition (loi n° 2017-20). Procédure : phase 2.

## Sécurité
Prototype : écoute locale uniquement, aucune donnée réelle. Chiffrement en transit et au repos : phase 2.
