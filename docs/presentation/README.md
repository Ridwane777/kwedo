# Présentation Kwedo

Sources du deck de présentation (11 slides animées, charte Kwedo). Publié comme artefact « Slides » dans Claude ; ces fichiers en sont la copie versionnée (`deck.json`, `deck.css`, `slides/*.html`, notes de présentation dans les balises `<aside>`).

Contenu : problèmes, solution, démonstration, gains par profil, moteur de risque, modèle économique (pilote, puis abonnement annuel ou licence), vision.

À compléter : noms de l’équipe (slide finale). Les montants de la slide « Afiavi » sont fictifs. Le suivi par WhatsApp est une fonction prévue, absente du prototype.

## Présenter (page unique)

Ouvrir `kwedo-presentation.html` dans Chrome : toutes les slides sont sur une seule page à faire défiler.
Touches : ↑ ↓ ou espace pour changer de slide, N pour les notes de présentation, F pour le plein écran.
Les animations se rejouent à chaque arrivée sur une slide. Connexion requise une première fois pour les polices Google (repli sur Arial sinon).
Régénérer après modification des slides : `python3 build.py`.
