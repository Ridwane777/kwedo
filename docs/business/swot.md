# SWOT

| Forces | Faiblesses |
|---|---|
| Outil de bout en bout pour le prêteur (dossier → décision → suivi) | Aucune donnée réelle ; impayés simulés |
| Explicabilité exacte (raisons recalculées, 100 % fidèles sur 39 dossiers) | Sur données simulées, ne classe pas mieux qu'une règle « médiane × k » |
| Décision humaine tracée, journal en ajout seul, rejeu à l'identique | Risque annoncé sous-estimé (≈ 13 points) |
| Détection de manipulation (100 % des cas injectés, règles + modèle) | Temps humain gagné non mesuré |
| Gratuit pour le commerçant, sans commission | Dépendance à l'accès aux flux de l'opérateur |

| Opportunités | Menaces |
|---|---|
| ≈ 11,66 M de comptes mobile money actifs (2025, **à recontrôler**) | L'opérateur lance sa propre offre (il a déjà un partenaire de scoring) |
| Écart inclusion stricte / élargie (39,8 % / 91,7 %, **à recontrôler**) | Cadre juridique du partage des données mobile money non clarifié |
| Facturation e-MECeF comme source vérifiable complémentaire | Surendettement par cumul de nano-crédits |
| Extensions : crédit fournisseur, chaînes agricoles, UEMOA | Usurpation d'identité |
